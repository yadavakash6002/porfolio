AKASH MOTION PORTFOLIO

Files:
- index.html: complete editable HTML, CSS, and JavaScript
- assets/profile-green.png: your green studio-style profile image

How to use:
1. Keep index.html and the assets folder together.
2. Open index.html in Chrome.
3. Edit index.html in VS Code to change text, colors, layout, and animations.
4. Replace assets/profile-green.png with another image using the same filename to change the portrait.

The profile image has subtle CSS motion effects. Project cards also contain CSS animations. Google Fonts requires internet; the page otherwise runs locally.
